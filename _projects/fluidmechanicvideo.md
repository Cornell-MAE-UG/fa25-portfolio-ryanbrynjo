# Overview
For my final project in Fluid Mechanics at Cornell University, we were tasked with a fluid dissection where we were given a machine and tasked with dissecting the machine and locating and describing the fluid mechanical component inside it. We were assigned an old printer.

I did this project with JT Thomforde (jht224@cornell.edu), Isaac Ng (in63@cornell.edu), Matthew Sonn (mjs676@cornell.edu), and Paige Cobrin (pac252@cornell.edu).

The main thing I did in this project was making diagrams for the inkjet process after researching  capillary action, cohesion, and adhesion. I also analyzed these concepts mathematically and how it tied into a static vs dynamic system, and the Navier Stokes equation.

Initially, the project started with taking apart the printer. Through this process, we found the ink cartridge and inkjet dispensing process to be the main fluid mechanical process in the printer.
